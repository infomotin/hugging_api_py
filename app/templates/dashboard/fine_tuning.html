Mathematical Foundations of Fine-Tuning

1. Empirical Risk Minimization & Cross-Entropy

min_θ ℒ_CE(θ) = -(1/N) Σ_{i=1}^N Σ_{t=1}^{T_i} log P_θ( y_t^{(i)} | x^{(i)}, y_{<t}^{(i)} )

The primary objective is minimizing Kullback-Leibler divergence between empirical token distributions and predicted probabilities across sequence length \(T\).

2. Low-Rank Adaptation (LoRA) Decomposition

W = W₀ + ΔW = W₀ + (α / r) · (B × A), where B ∈ ℝ^(d×r), A ∈ ℝ^(r×k), r ≪ min(d, k)

By freezing \(W₀\) and training only low-rank matrices \(A\) and \(B\), parameter storage and optimizer memory are reduced by over 70%, preventing catastrophic forgetting while preserving full model expressivity.

3. Information Perplexity (PPL) Derivation

PPL(θ) = exp( ℒ_CE ) = 2^{ H(P, Q) } = ( ∏_{t=1}^T 1 / P_θ(y_t | y_{<t}) )^(1/T)

Perplexity reflects the effective branching factor of the model. A decrease from PPL=11.5 to PPL=1.4 indicates the model is ~8x more certain on the target schema.

4. Cosine Annealing Learning Rate Dynamics

η_t = η_min + 0.5 (η_max - η_min) ( 1 + cos( π · t / T_max ) )

Smooth cosine deceleration prevents sudden loss spikes near convergence while facilitating escape from shallow local optima in the early epochs.
