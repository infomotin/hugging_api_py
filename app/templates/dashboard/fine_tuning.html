Mathematical Foundations of Fine-Tuning

1. Low-Rank Adaptation (LoRA)

W = W₀ + ΔW = W₀ + (α / r) · (B × A)

For a pre-trained weight matrix \(W₀ \in \mathbb{R}^{d \times k}\), LoRA constrains parameter updates \(\Delta W\) by factorizing it into two low-rank matrices \(B \in \mathbb{R}^{d \times r}\) and \(A \in \mathbb{R}^{r \times k}\), where rank \(r \ll \min(d, k)\). During training, \(W₀\) is frozen and receives no gradient updates. Only \(A\) and \(B\) contain trainable parameters, reducing GPU memory by ~70% and preventing catastrophic forgetting.

2. LlamaIndex ExtractBench Task Formulation

ExtractBench benchmarks the model's capability to map complex unstructured text into strictly structured JSON schemas.

x = (Document_Text, Target_JSON_Schema, Field_Rules)
y = Ground_Truth_Extracted_JSON_Object

3. Decoupled Weight Decay (AdamW)

m_t = β₁ m_(t-1) + (1-β₁) g_t
v_t = β₂ v_(t-1) + (1-β₂) g_t²
θ_(t+1) = θ_t - η_t · (m̂_t / (√v̂_t + ε)) - η_t · λ θ_t
